Hackathon Web App React

DriftCheck

React web app built for the VIT Hackathon. It tracks a person's lab results over time and flags "drift" from their own personal baseline instead of only comparing to population ranges. It shows a trend chart, a plain-language explanation of each result, and a "How was this identified?" section.
