# Nafeesath Nawfa L H F - Personal Portfolio

A fast, clean, and responsive single-page personal portfolio website built with plain HTML5, CSS3, and modern JavaScript. Designed for hosting on **GitHub Pages**.

## 🚀 Features

- **Lightweight & Dependable**: Built without heavy frameworks or build tools for maximum speed and reliability.
- **Dark & Light Mode**: Built-in theme switcher that saves user preference.
- **Fully Responsive**: Optimized for mobile, tablet, and desktop viewports.
- **Accessible**: Structured with semantic HTML5 elements, keyboard focus styling, and high contrast.
- **Interactive Lightbox**: Screenshot modal for exploring project visuals up close.

## 🛠️ How to Publish to GitHub Pages

1. **Initialize Git & Commit Files**:
   ```bash
   git init
   git add .
   git commit -m "Build portfolio website for website operations"
   ```

2. **Push to GitHub**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/NafeesathNawfa/NafeesathNawfa.github.io.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your repository on GitHub: `https://github.com/NafeesathNawfa/NafeesathNawfa.github.io`
   - Click on **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
   - Your website will be live in a few moments at: **https://NafeesathNawfa.github.io**
